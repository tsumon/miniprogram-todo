# Todo 清单 - 微信小程序

一个参考嘀嗒清单设计的待办事项管理小程序，原生开发（WXML/WXSS/JS），零依赖，打开即用。

## 功能特性

### 基础任务管理
- **今日待办**：展示今天到期和逾期的任务，支持进度追踪
- **全部任务**：按日期分组展示，支持搜索和状态筛选
- **新建任务**：优先级（4 级）/日期/时间/分类
- **任务详情**：查看/编辑，一键完成或删除
- **个人中心**：完成统计、连续打卡天数、今日进度

### AI 智能创建
- 文字/语音输入 → AI 意图识别，自动解析任务（标题/日期/优先级/分类）
- 支持多厂商：DeepSeek / 通义千问 / Kimi / 智谱 GLM / OpenAI 等（OpenAI 兼容接口）
- **双模式调用**：直连第三方 API 或云函数转发（云函数模式免服务器域名）
- 支持**多人多任务批量解析**（如"张三 8月8日 农历生日，李四 9月10日 新历生日"）

### 周期任务
- 日 / 周 / 月 / 季 / 年 五种周期 + 自定义间隔
- 支持「每季度第 N 周第 M 天」等复杂规则
- 到期自动生成下一期实例

### 农历生日提醒
- 支持公历 / 农历生日，AI 对话即可创建
- 农历跨年自动换算为公历日期，每年自动续期
- 生日任务默认每年提醒

### 日历
- 月视图 + 任务数徽标
- 点击日期查看当天任务列表
- 切换月份自动补全逾期周期/生日任务

### 提醒
- **应用内提醒**：到点弹窗，「标记完成」停止 /「稍后提醒」30 分钟后重弹
- 应用内提醒不依赖服务器，本地即可工作

## ⚠️ 消息推送说明（已弃用）

> **目前消息推送效果不好，已弃用。**

服务通知推送（微信订阅消息）曾实现过完整链路（云函数定时推送），但因以下原因弃用：

- **微信一次性订阅限制**：每次授权只能推送 1 次，需要每天手动授权，体验差
- **个人主体无法申请长期订阅**，无法实现稳定持续推送
- 体验版测试限制多，实际使用效果不佳

**当前提醒以应用内弹窗为主**（打开小程序即触发）。相关代码（`cloudfunctions/pushReminders`、`cloudfunctions/syncReminders`、`utils/push.js`）保留在仓库中，供有需要时参考，不再维护。

## 快速开始

1. 打开微信开发者工具 →「导入项目」
2. 项目目录选择 `todo-miniprogram`，填入你的 AppID
3. 直接运行，无需安装任何依赖，首次启动自动生成示例任务

### AI 功能配置（可选）

在「我的 → 设置」中：

1. 点选厂商预设（DeepSeek / 千问 / Kimi 等）自动填好 API 地址
2. 填入你的 API Key
3. 点「测试连接」验证，然后到首页点 AI 按钮开始使用

> 自用无服务器域名：把「AI 调用方式」切到**云函数**，部署 `cloudfunctions/aiProxy` 即可免域名白名单。

│   │   ├── empty-state/          # 空状态组件
│   │   └── recurrence-picker/    # 周期规则选择器

│       ├── date.js               # 日期工具

## 技术栈

- 原生微信小程序开发 (WXML/WXSS/JS)
- 本地存储 (wx.setStorageSync)，数据不上传
- 纯 CSS 绘制图标（无图片资源依赖）
- 可选：微信云开发（AI 云函数转发）
